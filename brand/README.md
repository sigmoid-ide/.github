# Sigmoid IDE brand

The mark is a sigmoid passing through a neuron. Outside the core the line is light; inside, it flips to dark.
The yellow dot is the output.

| File | Use |
|---|---|
| `sigmoid-ide.svg` | The app icon, 32 px and up |
| `sigmoid-ide-16.svg` | The app icon at 16 to 24 px, with heavier lines |
| `sigmoid-ide-512.png` | The app icon as a PNG |
| `avatar.svg`, `avatar.png` | Square without rounded corners, for GitHub and social avatars (they round the corners themselves) |
| `glyph.svg`, `glyph_dark.svg` | One-colour 16 px glyph for tool windows and toolbars, light and dark themes. The S is a real hole, so it works on any background |
| `lockup.svg`, `lockup-dark.svg` | The mark with "Sigmoid IDE", for light and dark backgrounds. The text is outlined, so no font is needed |

## Colours

| Name | Hex | Use |
|---|---|---|
| Night | `#14112B` | The tile, and "Sigmoid" on light backgrounds |
| Core | `#F4F1FF` | The core and the line, and "Sigmoid" on dark backgrounds |
| Signal | `#FFD166` | The output dot, and nothing else |
| Violet | `#6E56CF` | "IDE" on light backgrounds, badges and buttons |
| Violet light | `#A99BEA` | "IDE" on dark backgrounds |

The glyphs use the IntelliJ New UI icon colours: `#6C707E` on light themes, `#CED0D6` on dark.

## Type

[Space Grotesk](https://github.com/floriankarsten/space-grotesk) (SIL Open Font License): weight 600 for "Sigmoid",
400 for "IDE".

## Keep it recognisable

- Use the files as they are: don't stretch, rotate or recolour the mark.
- Below 32 px, use `sigmoid-ide-16.svg`; in a toolbar, the glyph.
- Each tool (Hunch, and the ones after it) has its own mark built the same way: the Night tile, light round-capped
  lines, and one yellow dot. Add each tool as a row in [the org profile](../profile/README.md).

The name and logo identify this project. Use them to link to or write about Sigmoid IDE, not to name other products.
