<p align="center"><b>An open-source, local-first IDE for ML research.</b><br>Built one tool at a time. Your work stays in plain files on your disk.</p>

| | |
|---|---|
| [**Hunch**](https://github.com/sigmoid-ide/hunch) | A journal for your ML experiments: every run keeps its code, config, environment, metrics and why you ran it. `pip install sigmoid-hunch` |
| [**Hunch for PyCharm**](https://github.com/sigmoid-ide/hunch-jetbrains) | Your runs as a tree in PyCharm. Compare any two in the diff viewer, keep or drop them. |
| [**Hunch for VS Code**](https://github.com/sigmoid-ide/hunch-vscode) | The same in VS Code, Cursor, Windsurf and VSCodium. |

<p align="center">Apache-2.0 · No accounts, no servers, no telemetry.</p>
